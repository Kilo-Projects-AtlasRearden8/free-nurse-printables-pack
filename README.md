# Free Nurse Printables Pack

Fillable, printable, no-account-needed worksheets for nurses: shift prep sheet, report brain sheet, CE (continuing education) log, and break-time checklist.

**Education only.** These tools are for organization and learning support. They are not medical advice, not a substitute for clinical judgment, and not a substitute for your facility's policies. Always follow your employer's protocols and state nursing practice act.

## Contents

| File | What it is |
|------|------------|
| `shift-prep-sheet.html` / `shift-prep-sheet.md` | Pre-shift setup: assignment, checklist, patient list, timeline, goals |
| `report-brain-sheet.html` / `report-brain-sheet.md` | SBAR-style handoff brain: patient snapshot, assessment, meds, lines, to-dos |
| `ce-log.html` / `ce-log.md` | Continuing education tracker: courses, hours, costs, renewal deadline |
| `break-time-checklist.html` / `break-time-checklist.md` | Before/during/after break checklist plus break-times log |

## How to use

1. Open any `.html` file in your browser (Chrome, Edge, Safari, Firefox). No account, no sign-up, no internet needed after you have the files.
2. Fill in the fields directly in the browser.
3. Press `Ctrl+P` / `Cmd+P` to print. Print styles hide on-screen controls and produce a clean worksheet.
4. Markdown (`.md`) versions are included if you prefer to edit, print from a markdown viewer, or copy into your own notes.
